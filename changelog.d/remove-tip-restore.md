### Fixed
- The tip jar no longer has a "Restore tips" button. App Review rejected 1.14 build 182 on 2026-10-08 under guideline 3.1.1: the button called `AppStore.sync()`, which asks for the Apple Account password, and tips are consumable purchases, which cannot be restored that way. Tips are still remembered: the supporter ledger is rebuilt from StoreKit's own transaction history at every launch (`reconcileWithStoreKitHistory`, which needs no sign-in, thanks to `SKIncludeConsumableInAppPurchaseHistory`). `TipJarStore.restore()` is removed with the button so nothing can call the password prompt again. Checked with a UI test that opens Settings → Support Wockett and asserts the button is gone, plus the 27 TipJarStore and SupporterLedger tests.
