### Changed
- The Help page on wockett.app uses the app icon's colours (forest green,
  cream, waypoint orange) instead of the old black-and-blue Apple look, the
  same palette scoopsdevstudios.com now uses, so the app's own help reads as
  part of the app. The colours are copied exactly from `DesignSystem.swift`,
  and every text colour clears WCAG AA contrast (ratios noted beside each
  token in the page's stylesheet). The bright orange stays decorative because
  it is too low-contrast for text on the green.
