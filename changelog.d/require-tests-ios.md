### Internal
- `Tests (iOS)`, the GitHub Actions job that runs the full `PoCSquat` scheme, is the required test check on `main` in place of Xcode Cloud's `Wockett | CI Tests | Test - iOS`. It was proven first: a throwaway PR with a deliberately broken unit test (#96) turned it red. Xcode Cloud's `CI Tests` workflow no longer starts on pull requests, so the 25 included compute hours a month go to Release Flow archives alone. The first real run took 32 minutes against Xcode Cloud's 7, and `testAccessoryBar` failed once at 324 s on the slower runner; a failed run now uploads its log and xcresult bundle, because the toolkit's `bin/test.sh` writes them under `TEST_OUTPUT_DIR` (Apple's `mktemp -t` ignores `TMPDIR`, which is why the first failure uploaded nothing). `CLAUDE.md` and `docs/ci.md` describe the new shape.
