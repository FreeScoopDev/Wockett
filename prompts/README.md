# Xcode-agent prompts

Audit trail of the prompts dispatched to the Claude in Xcode agent, one file
per implementation round, named `YYYY-MM-DD-short-name.md`. Committed so
"what was asked" lives next to "what was committed" — when a change needs
re-deriving later, the reasoning is here, not lost in a chat session.

Convention started 2026-08-29 (Pipeline Review); earlier rounds are
summarized in the Notion session-notes pages instead.
